# VPN Reseller Stack (Xray / X-UI + Telegram Sales Bot)

این پوشه شامل دو بخش است:

1. `server/` — اسکریپت نصب پنل X-UI (Xray core) روی سرور ۱ هسته/۱ گیگ شما و یک اسکریپت پایتون برای ساخت خودکار یک اینباند VLESS+Reality.
2. `bot/` — ربات فروش تلگرامی (شبیه نمونه‌ای که فرستادید) که پلن می‌فروشد، اطلاعات کارت و مبلغ دقیق را نشان می‌دهد، رسید را برای ادمین می‌فرستد و بعد از تایید ادمین به‌صورت خودکار از طریق API پنل X-UI اکانت VPN می‌سازد و لینک را برای مشتری ارسال می‌کند.

## قبل از هر چیز چه چیزهایی لازم دارم؟

این فقط کد است — من نمی‌توانم بدون اطلاعات زیر آن را روی سرور شما نصب/اجرا کنم یا ربات را واقعاً راه بیندازم:

- **IP سرور + راه دسترسی SSH** (رمز روت یا کلید). در اسکرین‌شاتی که فرستادید، آدرس IP و SSH پشت آیکون کپی مخفی بودند و متن قابل‌خواندن نبود — لطفاً خودِ مقدار IP و رمز عبور روت (یا کلید SSH) را به‌صورت متن بفرستید.
- **توکن ربات تلگرام** از @BotFather و **آیدی عددی تلگرام ادمین** (برای دریافت رسید و تاییدها). آیدی عددی را می‌توانید از @userinfobot بگیرید.
- **شماره کارت واقعی خودتان + نام صاحب حساب** که قرار است پرداخت‌ها به آن واریز شود (من نمی‌توانم شماره کارت واقعی برای شما حدس بزنم یا وارد کنم — این باید خودتان بدهید، در فایل `.env` قرار می‌گیرد).
- **لیست پلن‌ها و قیمت‌ها** (چند گیگ / چند روز / چند تومان) — در `bot/config.py` یک نمونه گذاشته‌ام، خودتان ویرایش کنید.

هر چهار مورد بالا را که فرستادید، می‌توانم مستقیم روی سرورتان نصب و راه‌اندازی کنم و ربات را هم بالا بیاورم.

## نحوه‌ی تایید پرداخت

چون به API بانکی/درگاه پرداخت متصل نیستیم، تایید پرداخت به‌صورت «نیمه‌خودکار» طراحی شده: مبلغ دقیق برای هر سفارش با یک پسوند ۲ رقمی یکتا نمایش داده می‌شود (مثل نمونه‌ی خودتان: ۶۰۰۰۲ به‌جای ۶۰۰۰۰) تا در صورتحساب بانکی راحت تشخیص داده شود، و ادمین با یک دکمه در تلگرام آن را تایید می‌کند؛ به محض تایید، اکانت VPN به‌صورت خودکار ساخته و لینک برای مشتری ارسال می‌شود. اتصال مستقیم به پیامک بانک برای تایید کاملاً خودکار عمداً پیاده نشده (نیاز به دسترسی به گوشی/پیامک شما دارد و ریسک و پیچیدگی اضافه می‌کند)؛ اگر خواستید بعداً اضافه می‌کنیم.

## اجرای سریع (بعد از دریافت اطلاعات سرور)

```bash
# روی سرور، به‌عنوان root:
bash server/install-xui.sh

# بعد از نصب پنل، از روی هر ماشینی که پایتون دارد (یا خودِ سرور):
python3 server/setup_inbound.py   # یک اینباند VLESS+Reality می‌سازد و اطلاعات لازم برای .env را چاپ می‌کند

# سپس ربات را تنظیم و اجرا کنید:
cd bot
cp .env.example .env   # و مقادیر را پر کنید
pip install -r requirements.txt
python3 main.py
```

برای اجرای دائمی روی سرور، یک سرویس systemd هم در پایین `server/install-xui.sh` توضیح داده شده.
