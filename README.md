# لیلیکا (LiLika)

پیام‌رسانی مستقل با برند خودت که روی زیرساخت **تلگرام (MTProto)** کار می‌کند —
همان مدلی که پیام‌رسان‌هایی مثل هاتگرام و تلگرام طلایی از آن استفاده می‌کردند.

کاربر با شمارهٔ تلگرام خودش وارد می‌شود، همان گفتگوها، گروه‌ها و کانال‌ها را
می‌بیند و پیام‌هایش با کلاینت‌های رسمی تلگرام کاملاً همگام است. تفاوت در
پوسته، زبان و تجربهٔ کاربری است، نه در شبکه.

![وضعیت](https://img.shields.io/badge/build-passing-2ea6a0) ![پروتکل](https://img.shields.io/badge/MTProto-GramJS-2ea6a0)

## چه چیزی پیاده‌سازی شده

| بخش | جزئیات |
| --- | --- |
| ورود | شماره → کد → رمز دومرحله‌ای (SRP) → ثبت‌نام برای شماره‌های جدید |
| گفتگوها | فهرست کامل با صفحه‌بندی، سنجاق، بی‌صدا، شمارندهٔ نخوانده، جستجوی سراسری |
| پیام‌ها | تاریخچهٔ صفحه‌بندی‌شده، ارسال، پاسخ، ویرایش، حذف، بازفرست، جستجو در گفتگو |
| قالب متن | bold، italic، code، pre، spoiler، لینک، منشن، هشتگ |
| رسانه | عکس، ویدیو، صوت، پیام صوتی، استیکر، گیف، فایل — با پیش‌نمایش مات و دانلود درخواستی |
| هم‌زمان | پیام جدید، ویرایش، حذف، «در حال نوشتن…»، آنلاین/آخرین بازدید، رسید خواندن |
| ظاهر | تیره/روشن/سیستم، پنج رنگ اصلی، اندازهٔ متن، RTL کامل، واکنش‌گرا تا عرض ۳۹۰px |

## معماری

```
مرورگر
  └── React (UI)
        └── src/lib/telegram/*      ← تنها لایه‌ای که با GramJS حرف می‌زند
              └── GramJS (MTProto over WSS)
                    └── دیتاسنترهای تلگرام
```

هیچ سروری در میانه نیست. مرورگر مستقیم با دیتاسنتر تلگرام رمزنگاری‌شده حرف
می‌زند؛ پروژه فقط فایل‌های استاتیک است. جزئیات بیشتر در
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## راه‌اندازی

```bash
npm install
cp .env.example .env      # اختیاری
npm run dev               # http://localhost:5173
```

### کلید API

هر نصب باید `api_id` و `api_hash` **خودش** را داشته باشد؛ تلگرام کلیدهای
مشترک بین چند برنامه را مسدود می‌کند.

۱. به [my.telegram.org](https://my.telegram.org) برو → API development tools
۲. یک برنامه بساز و `api_id` / `api_hash` را بردار
۳. یا در `.env` بگذار:

```env
VITE_TG_API_ID=1234567
VITE_TG_API_HASH=0123456789abcdef0123456789abcdef
```

اگر `.env` خالی باشد، برنامه در اولین اجرا صفحهٔ ورود کلید را نشان می‌دهد و
مقدار را فقط در `localStorage` همان مرورگر نگه می‌دارد.

### ساخت خروجی

```bash
npm run build     # dist/ — فایل استاتیک، روی هر CDN یا nginx قابل میزبانی است

```

### فونت

پشتهٔ فونت روی `Vazirmatn` تنظیم شده ولی فونتی از اینترنت بارگیری نمی‌شود —
برای شبکه‌های محدود عمداً این‌طور است. برای ظاهر بهتر، فایل‌های Vazirmatn را
در `public/fonts/` بگذار و یک `@font-face` به `src/styles/app.css` اضافه کن.

## نکته‌های مهم

- **دسترسی شبکه:** مرورگر باید بتواند به `*.web.telegram.org` روی WSS وصل شود.
  اگر این مسیر بسته باشد، برنامه پیام «اتصال برقرار نشد» می‌دهد و نشست ذخیره‌شده
  را دست‌نخورده نگه می‌دارد.
- **نشست:** رشتهٔ نشست در `localStorage` ذخیره می‌شود. هرکس به آن مرورگر
  دسترسی داشته باشد به حساب هم دسترسی دارد — روی دستگاه مشترک از «خروج از
  حساب» استفاده کن.
- **قوانین تلگرام:** ساخت کلاینت شخص ثالث مجاز است، اما
  [شرایط استفاده از API](https://core.telegram.org/api/terms) را رعایت کن؛
  ارسال انبوه و اسپم به مسدودی `api_id` منجر می‌شود.
